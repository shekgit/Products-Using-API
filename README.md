# React E-Commerce Store - Complete Shopping Experience

## Project Overview
A full-featured e-commerce application built with React, featuring product catalog, shopping cart, persistent storage, and modern UI. This single-page application (SPA) demonstrates professional React development with Context API, React Router, and Tailwind CSS.

## Tech Stack
- **Frontend**: React 18, React Router DOM 6, JavaScript ES6+
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Custom Animations
- **State Management**: React Context API + LocalStorage
- **API Integration**: FakeStore API for product data
- **Deployment**: Ready for Vercel

## Key Features

### Complete Shopping Experience
- Product Catalog: Grid/list views of all products
- Product Details: Detailed view with images, descriptions, ratings
- Shopping Cart: Add/remove items with persistent storage
- Favorites/Wishlist: Save products for later
- Stock Management: Real-time inventory tracking

### Advanced Routing
- Nested Routes: Products with dynamic product details
- Dynamic Navigation: Active link highlighting with animations
- 404 Error Handling: Custom error pages
- SPA Navigation: Smooth transitions between pages
